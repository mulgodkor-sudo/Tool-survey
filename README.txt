=========================================================
 Tool Survey v1.0  -  팀 공용 툴 설문조사
=========================================================

Hub 포털에서 팀원 각자가 설문에 응답하고, 그 결과를 표로 모아 보는 툴입니다.

[ 어떻게 켜지나 ]
  EngineeringHub\start_all.bat 을 실행하면 자동으로 같이 켜집니다.
  (apps\ 안에 start.bat 이 있는 폴더는 런처가 알아서 찾습니다)
  포트 : 8113   (방화벽 규칙 8101-8120 안에 들어 있어 추가 작업 없음)
  단독 실행 : start.bat 더블클릭

[ 처음 한 번 해야 하는 일 ]
  1. 포털(:8080) > Tool Survey 카드로 들어갑니다. 관리자만 편집 버튼이 보입니다.
  2. [설문 편집] 에서 묻고 싶은 툴 목록과 문항을 확인/수정합니다.
     - 처음 실행하면 Hub에 올라가 있는 툴 6종으로 문항이 미리 들어가 있습니다.
     - 툴 추가/삭제, 질문 추가/삭제, 보기 수정 모두 이 화면에서 됩니다.
  3. 공개 상태를 "진행중" 으로 바꾸고 [저장] 하면 그때부터 팀원이 응답할 수 있습니다.
  4. 다 받으면 "종료" 로 바꿉니다. 결과는 계속 볼 수 있고 응답만 막힙니다.

[ 문항 구조 ]
  1번  어떤 툴을 아는지 (툴마다 4지선다 : 자주 쓴다 / 몇 번 써봤다 /
       들어는 봤다 / 처음 들어본다)
  2번  툴마다 반복되는 평가 문항. 1번 답에 따라 묻는 내용이 갈립니다.
         써본 사람   -> 편한가 / 도움이 되나 / 불편한 점 / 개선 요청(서술)
         안 써본 사람 -> 왜 안 쓰나 / 설명 들으면 쓸 생각 있나
  3번  Hub 전반 공통 문항 (접속 빈도, 가장 유용한 툴, 새로 필요한 툴 등)

[ 결과 보기 ]
  요약 / 툴별 상세 / 서술형 모아보기 / 응답자 현황 네 가지 탭.
  미응답자 명단이 나오므로 독촉용으로 쓰면 됩니다.
  [CSV 내보내기] 는 엑셀에서 바로 열리는 UTF-8 BOM 형식입니다.

[ 익명 설문 ]
  설문 편집 화면에서 "익명" 을 켜면 결과·CSV 에서 이름이 빠집니다.
  단, 누가 제출했는지(응답률 계산)는 서버가 알고 있어야 하므로
  DB 에는 아이디가 남습니다. 완전 익명이 필요하면 그렇게 쓰지 마세요.

[ 데이터 ]
  apps\ToolSurvey\data\toolsurvey.db  (releases 번호를 올려도 지워지지 않음)
  백업은 이 파일 하나만 복사하면 됩니다.

[ 업데이트 ]
  releases\2\ 를 만들어 넣고 start.bat 의 경로를 2 로 바꾼 뒤 재시작.

[ 만든 방식 ]
  Python 표준 라이브러리 + 순수 HTML/CSS/JS 만 사용합니다.
  외부 패키지도 CDN 도 쓰지 않으므로 인터넷이 막힌 서버에서 그대로 돕니다.
